# ACMA — AI-Powered Classroom & Meeting Assistant

Progressive web app for PC and mobile. Live engagement dashboard, diarized captions, participation flags, and automated minutes.

**Repo:** https://github.com/buhessa90256/acma

## Run

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

On a phone: Chrome/Safari → Add to Home Screen.

## Notes

Vision, Whisper diarization, and LLM summarization are simulated in this build so the product flow works without room hardware. Optional device camera and Web Speech API are used when the browser allows them.
